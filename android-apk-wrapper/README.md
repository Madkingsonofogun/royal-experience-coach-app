# Royal Experience Android APK Wrapper

This folder contains a separate Android wrapper for the Royal Experience Smart Fitness Coach web app.

The original web app is not replaced by this wrapper. The APK packages a copied build of the web app from `www/`.

## Download APK

The debug APK is here:

`apk-download/royal-experience-debug.apk`

On GitHub, open this branch and download that file to an Android phone.

## Install Notes

- This is a debug APK for testing.
- Android may ask you to allow installing apps from your browser or file manager.
- iPhone cannot install APK files.
- For a Play Store version later, build a signed release APK or AAB.
